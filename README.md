# R_Projects

A collection of my R programming, data analysis, statistical modeling, and visualization projects, ranging from foundational exercises to more comprehensive, research-oriented portfolio work.

## About This Repository

This repository documents my development of practical R skills through two types of work:

- **Foundational projects:** Short exercises covering R syntax, data manipulation, regression modeling, and data visualization.
- **Portfolio projects:** More complete analytical studies that bring together data preparation, modeling, interpretation, and reproducible reporting.

## Portfolio Projects

The `Portfolio_Project` directory contains two more substantial projects with supporting analysis files and reports:

| Project | Overview | Methods & Tools |
|---|---|---|
| [Bellabeat Smart Device Usage Analysis](./Portfolio_Project/01Bellabeat_Smart_Device_Usage_Analysis/) | Exploratory analysis of wearable-device data to investigate daily activity, sedentary behavior, calorie expenditure, and sleep patterns. | R, data cleaning, descriptive statistics, correlation analysis, visualization |
| [Brain MRI Image Segmentation](./Portfolio_Project/02Brain_MRI_Image_Segmentation_Portfolio_Project/) | An exploratory image-analysis project using unsupervised learning to segment brain MRI images and examine how clustering-based image representations vary across images. | R, R Markdown, K-means clustering, image segmentation, CSV data, HTML/PDF reporting |

The Bellabeat project focuses on behavioral data analysis, while the MRI project demonstrates unsupervised image segmentation. The MRI folder includes a project-specific README, CSV data, R Markdown source, rendered HTML and PDF outputs, and a PDF report. See each project’s own README for its analytical workflow, results, and limitations.

## Skills & Methods

Across the repository, the projects demonstrate R programming, data wrangling, exploratory data analysis, regression, visualization, unsupervised learning, and reproducible analytical reporting.

The foundational folders emphasize individual techniques, while the portfolio folder shows how these techniques can be combined into more complete analytical workflows.

## Notes

Projects vary in scope and purpose. Foundational exercises are intended for learning and practice; portfolio projects provide more extensive analysis and documentation. For data sources, modeling assumptions, and findings, refer to each project's own files.
